# Pasta Lab & Smoked Flavors

Multilingual hospitality microsite concept for a Tallinn pasta bistro built with Astro, Tailwind and Vercel SSR.

## Scope

- localized experiences in Italian, English, Estonian and Russian;
- homepage, menu, story and booking flows;
- shared brand, SEO and structured-data systems;
- Astro Actions foundation for booking requests;
- Sanity-ready editorial/content architecture.

This repository is a portfolio/demo project. Booking persistence, email delivery and production operations still require deployment-specific configuration.

## Development

```sh
npm install
npm run dev
npm run build
```

Project decisions and implementation history are documented in [`docs/`](./docs/). Repository classification is recorded in [`REPOSITORY_STATUS.md`](./REPOSITORY_STATUS.md).
